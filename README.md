# 기숙사 볼링

방에서 즐기는 10프레임 3D 볼링 게임입니다. 설치할 것 없이 브라우저에서 바로 열립니다.
마우스, 손가락(터치), 키보드, 그리고 웹캠 손동작으로 던질 수 있습니다.

**▶ 바로 하기: https://sunlitkoreakorea.github.io/dorm-bowling/**

## 이렇게 던져요

**당겨서 놓기 (기본)**

1. 공을 옆으로 끌면 서는 위치가 바뀝니다.
2. 아래로 당기면 세기(파워)와 방향이 정해지고, 놓으면 발사됩니다.
3. 스핀은 아래 슬라이더로 줍니다.

**Wii식 스윙**: 위치 → 조준 → 누른 채 아래로 당겼다가 위로 휙. 옆으로 휘면 스핀이 걸립니다.

**키보드**: `← →` 위치 · `Shift+← →` 방향 · `스페이스` 길게 눌러 세기(누르는 동안 `← →`로 스핀) · `↑ ↓` 공 무게 · `Tab` 점수판 · `M` 소리

**카메라 손동작** (위쪽 `손 인식` 버튼)

- 엄지와 검지를 모으면 공을 잡습니다. 잡은 채 옆으로 끌면 위치가 바뀌고, 손을 아래로 내렸다가 손가락을 펴면 발사됩니다.
- 손을 옆으로 휘어 던지면 스핀이 걸립니다.
- 버튼 위에서 핀치하면 클릭이 됩니다.
- 영상은 브라우저 안에서만 처리되고 어디로도 전송되지 않습니다.

## 특징

- 1~4명 번갈아 치기, 정식 10프레임 점수 계산(스트라이크·스페어·10프레임 보너스)
- 공 무게 선택(8~16lb): 무거울수록 핀을 세게 밀어내지만 느리고 덜 휩니다
- 직접 만든 핀 물리: 공·핀 충돌, 거터, 핀이 튀고 구르는 연출
- 휴대폰·PC 모두 지원, 효과음은 브라우저에서 합성합니다

## 개발

`index.html` 한 장이 전부이고, 소스는 `src/` 에 있습니다.

```bash
python build.py     # src/ 를 합쳐 index.html 생성
```

- `src/bowling.src.html`: 화면·3D·입력·게임 진행
- `src/phys.js`: 핀 물리(Node에서도 돌려 볼 수 있어 확률 튜닝에 썼습니다)
- 3D는 [three.js](https://threejs.org/) r128, 손 인식은 [MediaPipe Tasks Vision](https://developers.google.com/mediapipe) 을 CDN 에서 불러옵니다

## 참고

닌텐도 Wii Sports 볼링의 조작 방식에서 영감을 받은 개인 프로젝트입니다. 닌텐도의 캐릭터·이미지·음원은 사용하지 않았고, 모든 그래픽과 효과음은 직접 만들었습니다.
